# 3–5分钟双客户端演示脚本

这是录制脚本，尚不是已录制的视频。使用本机已保存资产，DX11+30fps启动；先完整构建，再正常进入Lobby，PIE两人Listen Server。关闭网络模拟。全程以实际玩家窗口为准。

| 时间 | 操作 | 应展示 |
| --- | --- | --- |
| 0:00–0:30 | 两端进入大厅，等待进入比赛 | 两端同一比赛阶段与倒计时 |
| 0:30–1:00 | 默认步枪移动、瞄准、短按射击 | 转向/IK、FOV、准星、弹药扣减 |
| 1:00–1:40 | E拾取Carbine，Q切换；再拾Shotgun | 三种模型，主副弹药独立保留 |
| 1:40–2:20 | 对方站在通畅射线上，射击至淘汰 | 两端生命同步、得分、公告、3秒重生 |
| 2:20–2:50 | R换弹，拾取生命/弹药/加速 | 数值与生命周期一致 |
| 2:50–3:30 | 到比赛结束，尝试继续开火 | Results阶段拒绝射击，随后新一轮 |
| 3:30–4:30 | 可另录延迟测试片段 | 标明模拟参数与实测Ping，展示Hitscan命中 |

武器测试平台大约在世界坐标Y2570，三个生成点X=-550/-370/-190。服务器生成的拾取物有文字标签。演示时需要正常走到位置；调试传送证据与自然操作演示应分开标注。

射击时不要让栏杆隔在枪口与目标之间。此前实际查到Carbine生成点附近有栏杆遮挡；应走到通畅位置再射击。

录制前核对：MatchTime120、Warmup10、Cooldown10；无未保存包；新一轮无旧测试武器/墙；两端输入窗口正确。若出现崩溃或丢失内容，保留日志，不剪辑伪装成完整通过。
