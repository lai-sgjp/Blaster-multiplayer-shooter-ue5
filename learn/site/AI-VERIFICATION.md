## 安全边界

Key 在仓库外、Windows 用户 DPAPI 密文中；前端只拿到 hasKey 布尔状态。API 地址不得携带凭据/查询串，远端要求 HTTPS；更换地址必须重填 Key，重定向拒绝。POST 校验 Host、Origin 和页面 token，静态文件白名单排除源码服务端/配置。请求/响应有大小限制和超时，模型不能调用工具执行文件操作。

评价文本、原始回答与进度建议是数据；JSON 结构验证不代表模型必然正确。进度建议必须用户点击采纳，只补充学习自评和复习状态，不生成运行验证证据。Key 不在模型提示里；模型和服务错误不会回显配置的 Key。

`.gitignore` 与暂存区 secret guard 分别处理常见秘密文件和常见密钥文本；扫描不可能识别所有自定义格式，因此根本保障仍是密钥不进入仓库。hook 按当前用户授权安装到本仓库，新克隆需启用 hooksPath。

本轮新增功能无第三方运行时 npm 包，依赖 Node 内置 HTTP/fetch/crypto 和 Windows 系统 PowerShell。按仓库流程运行 npm audit 会因没有 lockfile 返回 ENOLOCK，不标为漏洞扫描通过。旧 Python-Markdown 内容生成依赖审计限制沿用原验证文档。
