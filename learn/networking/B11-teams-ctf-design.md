## Team Deathmatch

GameMode在PostLogin按人数平衡分配Team；PlayerState复制Team枚举，Character根据OnRep更新颜色。出生点按Team标签选择，找不到合法点时回退并记录错误。GameMode统一过滤同队伤害；计分只由首次淘汰事件推进GameState中的队伍分数。离开时从在线队伍统计移除，跨回合清分但保留队伍。

## Capture the Flag

Flag由服务器维护AtBase/Carried/Dropped状态、所属队伍、持旗者及返回计时器。敌方存活角色请求拾旗，服务器验证重叠、比赛阶段、归属和未持其他旗帜。持旗者淘汰或退出时释放；己方触碰掉落旗帜回收。进入己方得分区需要携带敌旗且己旗在基地，服务器原子处理一次得分与旗帜重置。客户端仅显示复制状态，不自行加分。

| 验收 | 预期 |
| --- | --- |
| 两队加入、晚加入 | 人数平衡、颜色与队伍分数一致 |
| 友伤/自伤 | 按统一规则过滤，不从客户端决定 |
| 错误队伍出生点 | 不出生在敌方点，明确回退 |
| 两人同帧拾同一旗 | 仅一名持旗者 |
| 本队旗未归位 | 敌旗不能提交得分 |
| 重复得分重叠 | 只增加一次队分 |
| 持旗者淘汰/退出 | 旗掉落或回基地，不留悬空引用 |
| 回合结束 | 清返回计时器、重置旗、禁用拾取 |
| 延迟/晚加入 | 从GameState与Flag复制恢复，不依赖曾收到事件 |
